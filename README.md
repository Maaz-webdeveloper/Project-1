# Stitch & Ink 🎨

A modern, fully responsive custom merchandise landing page built with HTML and Tailwind CSS. Stitch & Ink provides premium custom decorated merchandise solutions for companies, featuring online stores, warehousing, and fulfillment services.

## 🌐 Live Demo

Visit the live site: [https://project-1-nine-inky.vercel.app/](https://project-1-nine-inky.vercel.app/)

## ✨ Features

### Core Services
- **Merch Store** - Online stores custom-tailored to your brand
- **Merch Bundles** - Custom merchandise bundled together for employee or customer appreciation
- **Merch Storage** - On-demand warehouse and fulfillment solutions
- **Bulk Merch** - Volume discounts for large orders with brand consistency

### User Interface
- 🎯 **Fully Responsive Design** - Optimized for all device sizes (mobile, tablet, desktop)
- 🎨 **Modern UI/UX** - Clean, professional design with smooth animations and transitions
- 🖱️ **Interactive Elements** - Hover effects, smooth scrolling, and dynamic components
- 📱 **Mobile Menu** - Collapsible navigation for mobile devices
- 🎪 **Product Showcase** - Horizontal scrolling product cards with hover effects
- 🔄 **Brand Carousel** - Showcase of premium brands like Nike, Patagonia, Columbia, and more

### Key Sections
- Hero section with clear call-to-action buttons
- Service cards with detailed descriptions
- Brand partner showcase (18+ premium brands)
- Process timeline visualization
- Turnaround time comparison (Standard vs Rush vs Super Rush)
- Customer testimonial section
- Interactive order form
- Instagram integration showcase
- Comprehensive footer with newsletter subscription

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository
```bash
git clone https://github.com/Maaz-webdeveloper/Project-1.git
cd Project-1
```

2. Install dependencies
```bash
npm install
```

3. Open the project
```bash
# Simply open index.html in your browser
# Or use a local server like Live Server in VS Code
```

### Development
Since the project uses Tailwind CSS via CDN in production, you can directly open `index.html` in your browser. For development with custom Tailwind configurations:

```bash
# If you want to build custom Tailwind CSS
npx tailwindcss -i ./input.css -o ./style.css --watch
```
